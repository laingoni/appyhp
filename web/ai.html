AI that can see the connections.

AppyHP sends the selected module, its graph neighbors, project structure and current target source as context. The result is a complete source file plus a small connection review.

Configure a provider

Open AI settings from the Studio header. Add a provider, base URL, model and key. Compatible local providers can run without a key.

Generate deliberately

Select a module, write what it should do, then choose Generate. Live generation can be enabled per module or globally. A draft stays in the workflow until you save it.

Publish safely

Generated code is published to the configured folder and filename when you click Save or when Auto-save runs. If the target changes outside AppyHP, generation and file writes use conflict checks so you can review before replacing work.

Ask about a file

In Directories, open a file and click Info for the instant file-type explanation. Click Ask AI to have the configured provider explain the actual source contents.
