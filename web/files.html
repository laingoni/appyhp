The Directories panel is your source window.

Browse project folders, open editable text files, rename them, and save changes back to the Laravel application.

Explain and annotate

Info gives a quick explanation based on the file’s location. Ask AI reads the selected source and explains its actual behavior. Notes lets you record project-specific context for teammates and future AI prompts.

Context stays local

Your workflows, prompts, notes, encrypted provider settings and studio sessions live in the host application’s private storage/app/appyhp directory. They are not shipped as part of a fresh Composer installation.

File safety

Environment files, credentials, runtime storage, dependency directories and symbolic links are protected. Files must be valid UTF-8 text; the manual editor accepts up to 1 MiB, and AI editing accepts up to 128 KiB. Saves detect changes made by another editor. Reload the latest source and reconcile your edits when a conflict is reported.

File deletion is permanent and requires confirmation. Keep source control and backups; workflow undo does not restore deleted project files.

File actions

  • Right-click a file or folder to cut, copy, paste or delete.
  • Edit the filename in the editor header and click Save to rename it.
  • Edit source directly; Auto-save publishes changes in real time.

Keep your repository clean

Never commit private runtime state or AI credentials. If you choose a custom runtime path, add that path to your application’s .gitignore as well.
