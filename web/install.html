Install once. Start mapping.

AppyHP is a Laravel package for visually describing application architecture and turning that description into working source files.

Requirements

Use PHP 8.3 or newer and Laravel 13, with an application key and writable storage. An AI provider is optional for the canvas, scaffolding and manual editor.

Install with Composer

composer require alliswell/appyhp --dev
php artisan vendor:publish --tag=appyhp-config
php artisan appyhp:doctor

Enable the development studio when you are working locally:

APPY_MODE=dev

Then visit /appyhp/studio in your Laravel application.

Runtime context

AppyHP stores workflows, preferences, encrypted AI keys, notes and sessions in the host application’s storage/app/appyhp directory. State survives Composer updates and stays outside the public web root. Back up this folder if you need to retain your drafts.

For a host-specific runtime location, set APPYHP_RUNTIME_PATH to an ignored absolute path.

Local access and deployment

Studio accepts loopback requests by default. For a trusted development proxy, configure APPYHP_ALLOWED_IPS and APPYHP_ACCESS_TOKEN; authenticate with username appyhp and that token as the password. Remote access requires both settings.

Use APPY_MODE=dist and APP_DEBUG=false in production. Install production dependencies with composer install --no-dev. Clear or rebuild Laravel’s route and configuration caches when changing environments.

Upgrading older installs

If you previously used package-local .appyhp storage, back it up and copy the JSON state files into storage/app/appyhp, or explicitly retain its absolute path with APPYHP_RUNTIME_PATH. Keep the same APP_KEY to decrypt saved AI credentials. Existing state is not moved automatically.

Troubleshooting

Run php artisan appyhp:doctor. For a 404, verify APPY_MODE=dev and run php artisan optimize:clear. For a 403, check allowed IPs and the access token. For a 419, reload Studio to renew its session. If a save reports a conflict, download your workflow before reloading; another tab or editor may have changed it.

First session

  1. Open Studio and choose a workflow.
  2. Drag a module from the palette onto the canvas.
  3. Open the module editor and set its folder, filename and prompt.
  4. Click Save, or enable Auto-save.
